# Thomas Miller · brand kit

**Symbol: "Sommet qui perce".** An orange ring, open at the top, with the Moléson's peaks inside. The tall peak breaks out through the gap.
**Name:** "Thomas / Miller" on two lines in Archivo Expanded Black, with the tagline "Développeur web · Bulle".

All text is outlined, so the SVGs render the same everywhere without fonts installed.
`preview.png` shows every variant at a glance.

## Colours

| Name   | Hex       | Use                                              |
|--------|-----------|--------------------------------------------------|
| Orange | `#ff6a13` | The ring, accents. Close to Pantone 1585 C.      |
| Black  | `#121212` | Text, peaks, dark backgrounds                    |
| White  | `#ffffff` | Backgrounds, peaks on dark                       |
| Grey   | `#6b6b67` | Tagline on white (`#a3a39e` on black)            |

Orange is for shapes and large accents. Don't use it for small text on white: it's too light to read.

## Fonts (for the website, not needed for the logo files)

- Name and headings: **Archivo** Black (900), width 125 ("Expanded"), tracking −0.03em
- Tagline, labels: **DM Mono** Medium, uppercase, tracking +0.12em

Both are free on Google Fonts:
`https://fonts.googleapis.com/css2?family=Archivo:wdth,wght@125,900&family=DM+Mono:wght@500&display=swap`
then `font-family: "Archivo"; font-weight: 900; font-stretch: 125%;`.

## Which file where

| Need                             | File                                                    |
|----------------------------------|---------------------------------------------------------|
| Main logo                        | `svg/logo-color.svg` (two lines + tagline)              |
| Website header                   | `svg/logo-one-line-color.svg` / `-dark` for dark mode   |
| Without tagline                  | `svg/logo-no-tagline-*.svg`                             |
| Square spaces, covers            | `svg/logo-stacked-*.svg`                                |
| Symbol alone                     | `svg/symbol-*.svg`                                      |
| App icon / tile                  | `svg/icon-black.svg`, `icon-orange.svg`, `icon-white.svg` |
| LinkedIn, GitHub, Google         | `avatar/avatar-black-square.png` (the site crops it round) |
| Already-round avatar             | `avatar/avatar-*-circle.png`                            |
| Link previews (1200×630)         | `social/og-image-light.png`, `-dark`, `-orange`         |
| LinkedIn banner (1584×396)       | `social/linkedin-banner-dark.png`                       |

Colour suffixes: `color` = on white, `dark` = on black, `orange` = on orange,
`black` / `white` = single colour (stamps, engraving, one-colour print).

## Favicons

Copy everything in `favicon/` to your site root, then in `<head>`:

```html
<link rel="icon" href="/favicon.ico" sizes="32x32">
<link rel="icon" href="/favicon.svg" type="image/svg+xml">
<link rel="apple-touch-icon" href="/apple-touch-icon.png">
<link rel="manifest" href="/site.webmanifest">
<meta name="theme-color" content="#121212">
<meta property="og:image" content="https://thomasmiller.ch/og-image-light.png">
```

`favicon.svg` switches its peaks from black to white when the browser is in dark mode.
The PNG/ICO favicons sit on a black tile so they read on any tab colour.

## Rules

- Clear space around the logo: at least half the symbol's height.
- Smallest sizes: symbol 16 px; two-line logo 140 px wide. Below that, use the symbol or `logo-one-line`.
- Don't recolour the ring and peaks to other colours, stretch, rotate or outline the logo.
- On orange backgrounds use the `orange` files (white ring, black peaks), never the orange ring.

## Symbol geometry (64×64 grid)

- Ring: centre (32, 34), radius 25, stroke 6, round caps, open between −62° and 226.8°
  → `M43.74 11.93 A25 25 0 1 1 14.89 15.77`
- Peaks: `M17 45 L25.5 30 L31 38 L38.5 7 L47.5 45`, stroke 5, round joins and caps

## Rebuilding

Everything is generated by `build_kit.py` from the fonts in `fonts/` (Python 3):

```sh
python3 -m venv .venv && .venv/bin/pip install fonttools uharfbuzz resvg-py
.venv/bin/python build_kit.py .
magick favicon/favicon-16.png favicon/favicon-32.png favicon/favicon-48.png favicon/favicon.ico   # ImageMagick
```
