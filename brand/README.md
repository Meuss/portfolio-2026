# Thomas Miller · brand kit

**Symbol: "Sommet qui perce".** An orange ring, open at the top, with the Moléson's peaks inside. The tall peak breaks out through the gap.
**Name:** "Thomas Miller" in Schibsted Grotesk ExtraBold, on two lines, one line or stacked, with or without the tagline "Développeur web · Bulle".

All text is outlined, so the SVGs render the same everywhere without fonts installed.
`preview.png` shows every variant at a glance.

## Colours

| Name   | Hex       | Use                                              |
|--------|-----------|--------------------------------------------------|
| Orange | `#ff6a13` | The ring, accents. Close to Pantone 1585 C.      |
| Black  | `#121212` | Text, peaks, dark backgrounds                    |
| White  | `#ffffff` | Backgrounds, peaks on dark                       |
| Grey   | `#6b6b67` | Tagline on white (`#a3a39e` on black)            |

Orange is for shapes and large accents. Don't use it for small text on white: it's too light to read.

## Fonts (for the website, not needed for the logo files)

- Name in the logo, and website headings: **Schibsted Grotesk** ExtraBold (800), tracking −0.04em (titles use Bold 700)
- Website body text: **Schibsted Grotesk** Regular (400)
- Tagline, labels: **DM Mono** Medium, uppercase, tracking +0.12em

Both are free on Google Fonts and on Fontsource (`@fontsource-variable/schibsted-grotesk`,
`@fontsource/dm-mono`).
The name in the logo files is outlined from `fonts/SchibstedGrotesk.ttf` (variable, used at weight 800)
and the tagline from `fonts/DMMono-Medium.ttf`. These are the only two fonts the build needs.

The full website styleguide (dark colour tokens, type scale): https://claude.ai/artifact/Sn8r8BG7e8FA6TNQPVU1iu

| Need                             | File                                                    |

Colour suffixes: `color` = on white, `dark` = on black, `orange` = on orange,
`black` / `white` = single colour (stamps, engraving, one-colour print).

## Favicons

Copy everything in `favicon/` to your site root, then in `<head>`:

```html
<link rel="icon" href="/favicon.ico" sizes="32x32">
<link rel="icon" href="/favicon.svg" type="image/svg+xml">
<link rel="apple-touch-icon" href="/apple-touch-icon.png">
<link rel="manifest" href="/site.webmanifest">
<meta name="theme-color" content="#121212">
```

`favicon.svg` switches its peaks from black to white when the browser is in dark mode.
The PNG/ICO favicons sit on a black tile so they read on any tab colour.

## Rules

- Clear space around the logo: at least half the symbol's height.
- Smallest sizes: symbol 16 px; two-line logo 140 px wide. Below that, use the symbol or `logo-one-line`.
- Don't recolour the ring and peaks to other colours, stretch, rotate or outline the logo.
- On orange backgrounds use the `orange` files (white ring, black peaks), never the orange ring.

## Symbol geometry (64×64 grid)

- Ring: centre (32, 34), radius 25, stroke 6, round caps, open between −62° and 226.8°
  → `M43.74 11.93 A25 25 0 1 1 14.89 15.77`
- Peaks: `M17 45 L25.5 30 L31 38 L38.5 7 L47.5 45`, stroke 5, round joins and caps

## Rebuilding

Everything is generated by `build_kit.py` from the fonts in `fonts/` (Python 3):

```sh
python3 -m venv .venv && .venv/bin/pip install fonttools uharfbuzz resvg-py
.venv/bin/python build_kit.py .
magick favicon/favicon-16.png favicon/favicon-32.png favicon/favicon-48.png favicon/favicon.ico   # ImageMagick
```

## Link previews for the website (`build_og.py`)

The website's Open Graph images, one per page and language (`../public/og/<lang>-<page>.png`,
1200×630 PNG), are drawn by `build_og.py`. Each page has a layout (`LAYOUTS` in the script): most
show the logo, the page's headline and the domain; home shows only the logo, large and stacked
(symbol, name, tagline); about shows the logo over the portrait (`src/assets/profile.jpeg`, cropped
by `PORTRAIT_CROP`). It reads everything from the site: the pages are `sharePages` in
`src/data/share.ts`, each headline is `og.<page>.headline` in `src/i18n/ui.ts` (both locales), the
label is `brand.tagline`, the colours are the `--color-*` tokens in `src/styles/global.css`, and the
work card's screenshots are the first four projects on `/work` (`src/assets/projects/<slug>.jpg`).
Type is outlined from `fonts/`, like the logo files. Everything essential sits in the centre 630×630
square, because some apps crop previews to a square, and the text stays readable at 300 px wide.

The PNGs are committed; the site build never runs the script. Re-run it after changing a headline,
the tagline, the palette, the portrait or the project order (same venv as above, plus `pngquant`, which shrinks
the work and about cards: `brew install pngquant` on macOS):

```sh
cd brand
.venv/bin/python build_og.py                        # writes ../public/og/*.png
.venv/bin/python build_og.py --preview /tmp/og      # also 300 px wide and centre-square previews
```

To add a page: add its `og.<page>.headline` in both locales of `ui.ts`, add it to `sharePages` in
`src/data/share.ts`, pass `shareImage="<page>"` to `BaseLayout`, and run the script. A page with a
headline-less layout (`LAYOUTS`) has an `og.<page>.imageAlt` instead of a headline (the script
refuses a mismatch), used as its `og:image:alt`. `src/data/share.test.ts` fails if an image is
missing or shows an old headline (or, on the headline-less ones, an old tagline: a new portrait is
not detected).
